# کوشافن پارس (KFP Dental) - وب‌سایت رسمی دانش‌بنیان

وب‌سایت رسمی شرکت تولیدی مهندسی دانش‌بنیان کوشافن پارس (KFP Dental)، طراحی شده با فریم‌ورک Next.js 14، به صورت دوزبانه (فارسی و انگلیسی) و سئو بهینه‌سازی شده.

## ویژگی‌ها (Features)
- 💎 **طراحی مدرن و اختصاصی**: تم لوکس مدیکال/دندانپزشکی، گلس‌مورفیسم، انیمیشن‌های نرم و تایپوگرافی زیبا با فونت وزیرمتن و Outfit.
- 🌐 **دوزبانه کامل (Bilingual FA / EN)**: تغییر خودکار دایرکشن صفحه به راست‌چین (RTL) و چپ‌چین (LTR).
- 🏥 **صفحات اصلی**:
  - صفحه نخست (Home): هیرو سکشن، آمار، معرفی محصولات، بخش ویژه خدمات کوشایار، همکاران بین‌المللی (VITA, 3Shape, imes-icore) و سوالات متداول (FAQ).
  - درباره ما (About Us): تاریخچه ۳۰ ساله (۱۳۷۳ تا ۱۴۰۴)، پیام مدیرعامل، کلین‌روم کلاس ۱۰,۰۰۰ شمس‌آباد و گواهینامه‌های ISO 13485 و CE.
  - خدمات و محصولات (Services & Products): کاتالوگ کوره‌های پرسلن AT300 Plus, AT300P, AT100، کوره زینترینگ ۱۶۵۰ درجه، سیستم ایمپلنت اویتا (Avita)، میزهای لابراتواری و مودال استعلام قیمت.
  - مجله علمی و مقالات (Articles & Journal): مقالات بالینی، پژوهشی و دندانپزشکی دیجیتال با مدال خوانش.
  - تماس با ما (Contact Us): اطلاعات دفاتر شهرک غرب، کارخانه شمس‌آباد، فروشگاه سیناسنتر، فرم ارسال پیام و نقشه گوگل مپ.
  - نقشه سایت (Sitemap): صفحه بصری نقشه سایت برای کاربران و تولید خودکار `sitemap.xml` و `robots.txt` برای موتورهای جستجو.

## نحوه اجرا (Getting Started)

```bash
# نصب پکیج‌ها
npm install

# اجرای سرور توسعه (Development)
npm run dev

# ساخت و اجرای نسخه پروداکشن (Production)
npm run build
npm run start
```

## لینک‌های دسترسی
- پورت لوکال: `http://localhost:3000`
- سایت‌مپ: `http://localhost:3000/sitemap.xml`
- نقشه سایت بصری: `http://localhost:3000/sitemap`
- فایل روبات: `http://localhost:3000/robots.txt`
